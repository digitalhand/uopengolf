# OpenGolfCourse

Course terrain, physical surfaces, cups, scoring rules, flag cloth and vegetation wind. Depends on OpenFairwayPhysics.

## Use

Enable the plugin and assign its physical materials to course surfaces. Use terrain definitions for ground, and the flagstick and cup components for targets. Existing assets are ready to use; regeneration is a separate authoring task.
