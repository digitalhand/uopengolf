# OpenLaunchMonitor

Square Home Bluetooth input on Windows and Linux, Open Connect input, and replay shots through a game-instance subsystem.

## Use

Enable the plugin and obtain `UOpenLaunchMonitorSubsystem` from the game instance. Subscribe to its shot events, then connect a device or inject a replay shot. Device input is optional for development.
