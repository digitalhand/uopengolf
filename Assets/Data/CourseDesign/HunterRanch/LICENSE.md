# Hunter Ranch layout data

`corrections.json` adjusts a course layout derived from OpenStreetMap data. Like the derived layout,
it is made available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).

Each published course pack carries the full derived layout (`source_layout.json`, `source.geojson`
and `corrections.json`) next to its download, under the same licence. The project's code and other
content keep their own licences.
